# IPL Cricket Analytics Dashboard

## Overview
This project analyzes IPL cricket data using SQL and Power BI. The dashboard provides insights into team performance, player achievements, toss decisions, and match statistics.

## Technologies Used
- MySQL
- SQL
- Power BI
- VS Code

## Features
- Team win analysis
- Player of the match analysis
- Toss decision trends
- Matches hosted by city
- Batting and bowling insights

## Dataset
IPL dataset containing match-level and ball-by-ball data.
